JSONB annotation format

Annotate JSONB columns inside your DDL dump with line comments like:

-- @pg4-jsonb public.orders.payload customer.name:string
-- @pg4-jsonb public.orders.payload items[].sku:string
-- @pg4-jsonb public.orders.payload items[].qty:integer "quantity per cart item"

Paths use dotted notation; [] marks array segments. JSON Pointer (/customer/name) is also supported.

Privacy & local data

All data (DDL, schema graphs, history, snippets, usage) lives in your browser's IndexedDB and chrome.storage.local. PG4 does not upload, transmit, or phone-home anything. No cookies, no tokens, no database credentials are read.

About

PG4 Smart Assist is a parasitic enhancement layer for pgAdmin4 Query Tool.

  • Manifest V3 extension; runs in Chrome / Edge.
  • Offline-first: all schema, history, snippets stay on your machine.
  • No backend, no telemetry, no cookies, no DB credentials.
  • Compatible with pgAdmin4 v8.4 through v9.x (CodeMirror 6).
