  我一开始建了个仿真预览台（`.scratch/copy-menu-preview.html`）准备截图比对，**已按此约束删除**。
  → 结论：视觉改动别自作主张搭测试台，改 CSS 即可，由用户在真实环境验收。

### 落地要点（非显然的部分）

- 样式改为 **class 驱动**：新增模块级常量 `GRID_COPY_CSS`（`§10` 网格复制钩子开头）与 `MENU_ICON`，
  由 `pg4-copy-modified-style` 这个 `<style>` 一次性注入 iframe 的 `<head>`。
  旧的逐项 `element.style.cssText = ...` 全部废除，hover/focus 高亮交给 CSS，
  顺带删掉了 `onmouseenter/onmouseleave` 两个内联处理器。
- **配色纪律**：底/字色沿用 react-data-grid 的 `var(--color-bg)` / `var(--color-fg)` 以跟随 pgAdmin 明暗主题；
  边框与分隔线一律**半透明中性灰** `rgba(127,127,127,.28~.34)`，两种主题下都不刺眼；
  强调色用 PG4 蓝 `#2f6feb`（与右下控制面板、toast 的 3px 左竖条同源），保证我们这一层内部一致。
  **不要用 `color-mix()` / `oklch()`**——企业环境的浏览器版本可能偏旧，这类函数会整条规则失效。
- 旧版把按钮撑成 `min-width:48px` 并塞 "MOD" 文字，会扭曲 MUI ButtonGroup 的几何。
  新版**不动尺寸**，标记改用 `::before` 的 2px 左竖条 + `::after` 右上角 10px 圆形角标「4」，
  外加主题色渐变底。工具栏不位移，但仍一眼可辨。
- **`GRID_HOOK_REV` 必须 9 → 10**：`installGridCopyHook` 首行按 rev 短路，
  不升 rev 则已经在跑的 iframe 不会重装，新样式在热重载场景下不生效。
  对外 `VERSION` 保持 2.2.7——样式改动不升版本号（用户偏好，见 `decisions.md`）。
- 菜单条目**必须仍是 `<button>` 且带 `data-pg4-copy-mode`**：`onDocClick` 的拦截逻辑靠这两件事识别，
  同时菜单里的 `<span>`/`<i>` 装饰节点不能挡住 `closest("[data-pg4-copy-mode]")`。
- 条目顺序调整为「复制列名和数据」在首并标 `默认`（与主按钮点击行为一致），
  原来 `仅复制数据` 在首。`IN 条件` 仍单独分组在分隔线下，标出条数。
